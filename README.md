Welcome to my central project repository. This portfolio showcases my work in building intelligent systems that solve real-world engineering and business problems.

Starting as a Production Engineer, I realized that the future of efficient manufacturing lies in data intelligence. My transition began with Predictive Maintenance, where I applied Deep Learning (LSTMs) to solve physical problems like CNC tool wear. I then expanded into Natural Language Processing, building systems to automate technical knowledge retrieval (RAG) and recruitment processes. This portfolio represents my evolution from managing shop floor operations to architecting intelligent, data-driven solutions for Industry 4.0

This repository is organized into separate branches, each containing the full source code, documentation, and resources for a specific project. Please switch to the respective branch to explore the implementation details.

🚀 Featured Projects
1. 🤖 AI Machining Advisor (RAG)
Branch: feature/machining-rag (Link this in your actual repo) An intelligent chatbot designed for Production Engineering. It retrieves technical cutting parameters from manufacturer catalogs and performs physics-based calculations (RPM, MRR, Force) using Large Language Models.

      Tech Stack: LangChain, Ollama (Llama 3), ChromaDB, Streamlit.

2. ⚙️ Predictive Maintenance System (CNC Tool Wear)
Branch: feature/cnc-rul-prediction A deep learning solution for Industry 4.0. This system analyzes time-series sensor data (vibration, force, AE) to predict the Remaining Useful Life (RUL) of CNC tools, enabling proactive maintenance.

      Tech Stack: TensorFlow/Keras (LSTM), Optuna (Hyperparameter Tuning), Python.

3. 📄 Automated Resume Screening System
Branch: feature/resume-matching An NLP-based classification system that automates the recruitment process. It matches candidate resumes to job descriptions using text vectorization and gradient boosting classifiers to predict candidate suitability.

      Tech Stack: Scikit-Learn (TF-IDF), XGBoost, NLTK.
